# Project guidance

This directory is for organizing personal finance receipts and related records.
No application or file format is established yet; follow the formats already
present when adding files or code.

## Handling records

- Preserve original receipt files. Make edits or derived versions as separate
  files, and avoid overwriting source records.
- Keep dates, vendor names, totals, currencies, and tax amounts faithful to the
  source. Mark unavailable or unreadable details as unknown instead of guessing.
- Retain useful source filenames where possible. When creating a filename,
  prefer a consistent date-first format such as `YYYY-MM-DD_vendor_description`.
- Treat receipts and financial details as private. Do not copy their contents
  into external services, logs, examples, or documentation unless asked.
- Avoid adding credentials, payment card numbers, or unrelated personal data to
  generated indexes or metadata.

## Changes

- Keep changes focused on the requested receipt organization or project work.
- Before bulk renaming, conversion, or deletion, inspect the affected files and
  preserve a clear mapping back to originals.
- When extracting or summarizing information, retain a reference to the source
  receipt so entries can be checked later.
